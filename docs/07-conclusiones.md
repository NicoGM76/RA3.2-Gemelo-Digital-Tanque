# 7. Conclusiones

La actividad RA3.2 parte de una base ya funcional desarrollada en RA2.3 y la amplía hacia una arquitectura de gemelo digital.

Hasta el momento se ha comprobado que:

- el montaje físico conserva la lógica esperada,
- OpenPLC ejecuta correctamente las combinaciones de nivel,
- el Arduino UNO puede mantenerse como microcontrolador principal,
- la integración Modbus puede añadirse sin reemplazar el hardware existente,
- el computador puede emplearse como gateway para la futura conexión IoT.

La principal tarea pendiente es completar la comunicación efectiva entre Arduino y CODESYS y, posteriormente, validar la publicación y modificación del estado mediante la plataforma IoT.

Estas conclusiones se actualizarán después de la validación integral del sistema.
